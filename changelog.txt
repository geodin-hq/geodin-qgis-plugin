# Version __4.1.1.2648__ (11/2026)

* Changes
  * code quality checks (Flake8) of plugins.qgis.org pass
  * explicit imports instead of 'from ... import *'
  * 'except Exception:' instead of bare 'except:'
  * unused imports, variables and a duplicate method removed
* Fixes
  * obsolete GeoDinQGIS entries are removed from the QGIS project again (NameError 'oldKey')
  * from_json of project groups and ADC links raises NotImplementedError instead of NameError

# Version __4.1.0.2648__ (11/2026)

* Changes
  * security scan of plugins.qgis.org passes without a Bandit configuration (.bandit removed)
  * argument checks raise AssertionError explicitly (also with python -O)
  * plugin settings in <LocalAppData>\config.json instead of a shelve file; the language setting is reset once
  * GeoDin process check without tasklist; help, e-mail and Windows Explorer opened through the Windows shell
  * passwords are only masked by the central log formatter
  * opening a database shows 'Connecting to database ...'; errors name the database and point to the connection settings in GeoDin
  * support e-mail without CC

# Version __4.0.0.2644__ (10/2026)

* Changes
  * runs on QGIS 3.28 and newer (Qt5) and QGIS 4 (Qt6)
  * Oracle databases (FireDAC DriverID Ora) through the Python package oracledb 2.0+, no Oracle client needed
  * optional: load a DDX file automatically when QGIS starts
  * new tool "Create object": click in the map to create a GeoDin object at that point
  * tools Selection and Hotlink: choice of the GeoDin method that runs after the selection
  * layer styles (*.qml) for object and measurement point layers
  * GeoDin system queries in the object tree
  * check of the GeoDin COM server registration, with repair
  * support e-mail with logs and system information as ZIP
  * passwords are masked in the log files
  * spelling GeoDin / GeoDinQGIS
  * clear message on systems without Windows or pywin32
  * version scheme Main.Minor.Bugfix.YYWW

* Bug fixing
  * an invalid database entry (no DriverID) no longer breaks the whole GeoDin connection
  * misconfigured database: clear error instead of a login prompt
  * layers are only added if their GeoJSON exists and opens
  * CRS validity check
