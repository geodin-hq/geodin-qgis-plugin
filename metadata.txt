qgisMinimumVersion=3.28
qgisMaximumVersion=4.99
description=This plugin connects GeoDin with QGIS
about=GeoDin is an industry standard software for the collection, interpretation and presentation of geo-information. GeoDinQGIS is an additional tool for the work with GeoDin. It connects GeoDin with QGIS.
    Requirements: Windows with GeoDin installed, and the Python packages pywin32 and, for the database connections, pyodbc (MS Access, MS SQL Server), psycopg2 (PostgreSQL) or oracledb 2.0+ (Oracle). If QGIS reports a missing module, open the OSGeo4W Shell as administrator, run "python -m pip install pywin32 pyodbc psycopg2-binary oracledb" and restart QGIS.
